قابلیت جدید: لیست ادمین‌ها (Staff Directory)

فایل‌های جدید:
- staff-list.html / staff-list.js / staff-list.css: صفحه عمومی لیست ادمین‌ها
- staff-list-admin.html / staff-list-admin.js: پنل مدیریت Owner-only
- KARASO_STAFF_DIRECTORY.sql: ساخت جدول و سیاست‌های دسترسی Supabase

امکانات:
- نام نمایشی قابل تغییر
- رنک عددی صحیح؛ مرتب‌سازی خودکار نزولی (مثلاً 9، سپس 8، سپس 7)
- رول متنی آزاد؛ هر عنوانی که Owner وارد کند پذیرفته می‌شود.
- افزودن، ویرایش و حذف عضو
- نمایش عمومی اطلاعات و دسترسی مدیریت فقط برای Owner
- رنک‌های مساوی کنار هم می‌آیند؛ در رنک مساوی، اعضای قدیمی‌تر اول می‌مانند.

راه‌اندازی:
1) فایل KARASO_STAFF_DIRECTORY.sql را در Supabase Dashboard > SQL Editor اجرا کنید.
2) کل محتویات پوشه redo را در مخزن GitHub سایت جایگزین/آپلود کنید.
3) وارد حساب Owner شوید و از صفحه «لیست ادمین‌ها» لینک پنل مدیریت را باز کنید.

پیش‌نیاز: جدول public.profiles با ستون‌های id و role وجود داشته باشد و رول Owner دقیقاً مقدار 'owner' داشته باشد.
